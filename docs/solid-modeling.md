# 实体建模与布尔运算

本文以当前 Electron 工作台为准，见 [运行与界面说明](electron.md)。原 Qt 版本保留为兼容入口，逐次更新见 [开发记录](../DEVELOPMENT_LOG.md)。

点击顶部 **实体建模** 进入统一 Notebook 节点工作区。左侧从空白项目与“＋新节点”开始，实体与参数统一显示为可拖动卡片。有效实体默认同时预览，创建后展开编辑，有实体后显示底部“生成工作流”。最终模型来自 libfive，原始精度导出使用成功生成的最终网格；多实体布局是独立的查看状态。

![暗色实体组合：空心球壳、加强环与三向开孔](showcase-sphere-dark.png)

## 基本实体

| 对象 | 尺寸参数 | 默认方向 |
| --- | --- | --- |
| 球 | 半径 | 原点为球心 |
| 盒 | X/Y/Z 长度 | 原点为盒中心 |
| 圆柱 | 半径、高度 | 轴向为局部 Z |
| 圆环 | 主半径、管半径 | 环位于局部 XY 平面 |
| TPMS | 从原 TPMS 参数区读取独立参数快照 | 与原三轴定义相同 |

所有对象可设置 XYZ 位置（mm）与 XYZ 旋转（度）。采用绕 X、再 Y、再 Z 的旋转顺序，之后平移。尺寸均为实体本身的尺寸；“位置”不改变尺寸。组合对象也可以整体平移和旋转。

## 操作流程

1. 点击顶部“建模”中的基本体按钮，或在左侧点击“＋新节点”，搜索并选择基本体。
2. 展开实体节点编辑尺寸；展开“位置与旋转”设置变换。
3. 添加并集、交集、差集或平滑融合节点，在节点内选择“输入 A / B”；已有组合也可作为输入。
4. 在节点右键/“⋯”菜单选择“设为输出”，或在“输出设置”选择最终输出节点。
5. 在“输出设置”设置网格尺寸，点击底部“生成工作流”。完成后在右侧查看，并从顶部导出 STL/OBJ/PLY。

属性输入直接更新项目草稿，无需另点“应用属性”。在“全部实体”下，尺寸与位置更新后自动刷新各有效节点；在最终输出下保留上次生成结果并提示需要更新。正式导出等待重新生成。打开/保存项目位于顶部，保存的是参数和关系，打开后仍需生成最终网格。

| 操作 | 行为 |
| --- | --- |
| 并集 | 合并 A 和 B，可保留多个分离实体 |
| 交集 | 只保留 A 和 B 重叠区域；用圆柱/球/盒裁剪 TPMS 填充区域 |
| 差集 A−B | 从 A 挖去 B；顺序影响结果 |
| 平滑融合 | 按指定 mm 宽度圆滑连接两个基本实体组合 |

球、盒、圆柱、圆环采用距离函数构造。TPMS 场仍沿用原来的距离近似，不能作为精确距离场参与本阶段的平滑融合；该操作会明确拒绝 TPMS 输入，普通并集/交集/差集均支持 TPMS。

## 示例：圆柱内 Gyroid 与流道

空项目在“＋新节点 → 从示例开始”，有节点时在“设置 → 示例工作流”选择“圆柱 TPMS 减流道”，再点击底部“生成工作流”。

对象关系为：24 mm 盒域内的 Gyroid，与半径 10 mm、高 24 mm 的圆柱取交集，再减去半径 3 mm、高 30 mm 的贯穿圆柱。展开对应节点可修改外柱、流道尺寸或位置，然后重新生成。

要加入自己的 TPMS：切换到顶部“TPMS 建模”设置曲面/壁厚/孔隙率/尺寸/周期，切回“实体建模”，在顶部“TPMS 节点”工具栏点击“添加 TPMS”，或选中已有 TPMS 点击“使用当前 TPMS 参数”。对象保存参数快照，后续修改原参数不会悄悄改变已有 TPMS 对象。

另外提供“球体减贯穿孔”和“双球平滑融合”示例。加载示例会替换当前对象，请先保存需要保留的项目。

## 复杂组合示例

[Gyroid 双法兰](../examples/showcase/gyroid-flanged-core.json) 将圆柱点阵芯与两个环形法兰合并，减去四个安装孔和贯穿流道；[三向开孔球壳](../examples/showcase/perforated-ring-sphere.json) 则组合空心球壳、加强圆环及 X/Y/Z 流道。它们分别包含 19 和 11 个几何节点，可以继续编辑，并通过原始表面导出验证。

![双法兰复杂模型的纵向剖切](showcase-gyroid-section.png)

先用多实体半透明比较输入位置，再生成最终组合检查截面。组合只沿引用关系计算，列表顺序可调整；上游变换可以复用同一实体，不必重复定义公式。参数、节点关系、默认精度和实际验证见 [模型画廊](model-gallery.md)。

## 保存、生成与限制

同一“实体建模”工作区支持独立变换、类型化参数、引用定位、中间预览及工作流撤销重做，见 [节点式参数化建模](node-modeling.md)。简单实体直接填写尺寸，需要联动时再加入参数和公式。

- “保存项目/打开项目”存储可继续编辑的 JSON 参数与对象引用，不是仅保存 STL；旧 Qt 实体裸 JSON 和旧 Electron 实体项目自动在统一节点工作区打开，保存后采用节点项目模式；原生 DLL 仍需在目标机器安装。
- 允许复制和删除对象；被其他组合引用的对象须先删除依赖组合。输入关系检查循环引用，避免无限计算。当前最多 64 个对象。
- 网格尺寸是 libfive 最小划分尺度，不是目标面数或严格误差。细孔、薄壁需要足够小的尺寸并做收敛检查；对任意布尔组合不能保证所有特征都被自动识别。
- 生成失败（空交集、完全减空、过高精度、未封闭等）显示原因并保留上次结果。没有依赖时提示安装，见 [libfive 接入说明](libfive.md)。
- 生成后统计实际面数和体积。实体组合没有统一的参考填充域，因此不显示误导性的孔隙率或相对密度。
- 组合结果的 CFD/COMSOL 网格、仿真区域和质量操作暂时禁用。切回 TPMS 工作区并生成普通 TPMS 后恢复；本阶段只交付实体表面网格。
- TPMS GPU Ray Marching 用于内置 TPMS 工作区。实体组合使用 Three.js 网格视口，支持旋转、平移、缩放、右下角 XYZ 方向标、轴向视角和明暗主题。
- 平移后模型预览自动居中便于观察，导出文件保持原始世界坐标。
- 管状卷绕、网格导入变隐式实体、节点图自由布线、壳体自动偏置、STEP/B-Rep 尚未包含；节点工作区已支持上游实体引用和工作流撤销重做。

实现文件：`solid_model.py`、`libfive_backend.py`、`electron_backend.py`、`desktop/src/main.jsx`、`desktop/src/Viewport.jsx`。核心测试：`test_solid_model.py`；Electron IPC 与实机验收：在 `desktop/` 执行 `npm test`、`npm run verify-ui`。`solid_panel.py`、`app.py` 及 `scripts/verify_solid_ui.py` 仍用于 Qt 兼容版本。
