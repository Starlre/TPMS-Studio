# 深灰蓝配色

本配色按参考截图应用于 TPMS Studio，保留 Magpie 圆角界面的布局、字号、间距、控件尺寸和交互。默认展示深色；亮色主题使用对应的中性蓝灰色。桌面升级到该配色时首次进入深色，后续继续保存用户的主题选择。

| 角色 | 深色 | 亮色 |
| --- | --- | --- |
| 页面背景 | `#1B222C` | `#EEF2F6` |
| 面板 | `#1B222C` | `#FFFFFF` |
| 悬停 / 次级表面 | `#242E3A` | `#EDF2F7` |
| 输入框 | `#141B24` | `#F7F9FC` |
| 三维视口 | `#171E27` | `#E8EEF4` |
| 正文 | `#E6EDF5` | `#202F40` |
| 辅助文字 | `#A7B7C9` | `#536679` |
| 控件边界 | `#536679` | `#7D90A3` |
| 结构分隔 | `#354353` | `#C5D0DC` |
| 强调文字 / 图标 | `#79BCE1` | `#195B83` |
| 主按钮 | `#24638A` | `#24638A` |
| 主按钮文字 | `#FFFFFF` | `#FFFFFF` |
| 选中表面 | `#263E53` | `#E3EEF6` |
| 普通模型网格底色 | `#329EEA` | `#167AC2` |

普通单模型采用亮天蓝，与深灰蓝视口形成亮度差；亮色主题使用稍深的蓝色，保证轮廓清楚。网格粗糙度为 `0.42`、金属度为 `0.06`，白色主光形成柔和高光，蓝色补光保留暗部，淡蓝轮廓光突出薄壁与孔洞边缘。GPU 隐式预览采用相同蓝色并添加随视角变化的高光和轮廓光，不改动隐式曲面的求交与步进算法。

桌面与网页共享 `desktop/src/model_appearance.mjs` 中的材质、色值与灯光配置。效果通过现有材质和直接光照实现，不启用阴影贴图、后期泛光或额外反射渲染；多实体、剖切、测量及 CFD 诊断保留各自的语义颜色。

按 sRGB 色值计算，深色正文对面板约为 13.57:1、辅助文字约为 7.82:1；亮色正文对面板约为 13.62:1、辅助文字约为 5.92:1；主按钮白色文字约为 6.51:1。以上为基础文字与背景的对比度，不代表所有禁用状态或三维表面像素。
