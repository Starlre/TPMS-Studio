# Magpie 青绿色界面

希望在其他 App 中复现这套风格，可以阅读 [Magpie 青绿色 App 界面设计指南](Magpie青绿色App界面设计指南.md)，其中包含实际色值、控件尺寸、CSS 骨架和可复制的设计提示词。

TPMS Studio 桌面保持 Electron + React + Three.js，Python 进程继续负责建模与网格计算。视觉参考 Magpie 的浅青绿色背景、圆角卡片和轻量顶部栏，通过 HTML/CSS 实现；导航按桌面建模习惯放在顶部。

![亮色 TPMS 工作台](electron-tpms-light.png)

顶部文件栏集中打开、STEP 导入、保存、导出与主题切换；下一行切换 TPMS、实体建模及导入模型工作区，并提供模型统计、剖切测量和 CFD 设置。界面没有左侧分组导航。功能工具栏按工作区提供命令，可收起以扩大模型视图。

左侧参数按曲面、尺寸、周期及结构分组，常用参数横向排列，XYZ 保持并排。输入数值使用 16px 字体，生成按钮固定在底部；长内容单独滚动。中央保留 GPU 隐式预览、网格查看、轴向观察及 XYZ 方向标，右侧提供模型信息和剖切测量。

![实体节点卡片与最终输出](electron-notebook-cards-light.png)

实体与参数卡片沿用现有编辑、拖动排序、引用、上下游展开及撤销重做。选中卡片使用更浅的青绿色表面，输入框和菜单统一边框与圆角；生成按钮使用紫色。

![暗色 TPMS 工作台](electron-tpms-dark.png)

新用户默认亮色。右上角月亮/太阳切换主题，选择保存于本地；已有用户继续使用原来的主题偏好。暗色采用墨绿色表面和浅紫操作，操作文字使用深色以保持对比度。

## 运行与验证

双击项目根目录的 `启动Electron.cmd` 或 `run_tpms.bat`。启动器按需构建界面，无需打包可执行文件。

界面验证使用实际 Electron 窗口，覆盖明暗主题、1120 × 760 窗口、功能工具栏和键盘导航、节点编辑与真实生成、保存恢复、剖切测量及模型导出。已有建模和 IPC 单元测试继续执行。
